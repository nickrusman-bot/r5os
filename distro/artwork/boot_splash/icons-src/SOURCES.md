# Boot splash icons: sources

Seven Haiku vector icons, one per boot stage (`headers/private/kernel/boot_splash.h`). Downloaded as SVG from https://hvif-store.art/ on 8 Nov 2026. They are unmodified Haiku icons: MIT, copyright Haiku, Inc. and its contributors. The generator renders them to the 308×80 strip; it does not change the drawings.
