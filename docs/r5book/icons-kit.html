libr5icons.so

The Icons Kit

Icons for R5 programs through public calls only: Haiku's own HVIF icons as bitmaps of the size you ask for, icon buttons that line up with text buttons, and one-color line glyphs for the symbols Haiku's icon set does not have.

Sourcedistro/icons
Long descriptiondocs/ICONS.md

Do not open Tracker's private resources or read libtracker.so to draw an icon. Every call here goes through a public API: an HVIF buffer, a file's icon, or a MIME type's icon. None of them draws the Settings preferences wrench.

Icon bitmaps

functions

Each call returns a new B_RGBA32 bitmap of side × side pixels, or NULL. The caller deletes it. Ask for the size you will show: the bitmap is rendered from the vector at that size and stays sharp.

BBitmap* r5_icon_bitmap(r5_icon which, float side);

One of the predefined icons.

BBitmap* r5_vector_icon_bitmap(const uint8* data, size_t size, float side);

Any HVIF icon you already have, for example from a resource or an .inc file.

BBitmap* r5_file_icon_bitmap(const char* path, float side);

The icon of a file or folder, through the public node API.

BBitmap* r5_mime_icon_bitmap(const char* type, float side);

The icon of a MIME type, for example "application/x-vnd.Be-PEPL" for the People icon that Sign in uses as the account picture.

#include <R5Icons.h>

BBitmap* home = r5_icon_bitmap(R5_ICON_HOME, 32);
BBitmap* people = r5_mime_icon_bitmap("application/x-vnd.Be-PEPL", 30);
// ... draw them pixel for pixel, then:
delete home;
delete people;

Icon buttons

functions

A text button gets its height from the font. An icon button next to it has to use that same height, or the row looks uneven. These calls make a BButton a square of the height you pass and draw the icon inside it, one pixel clear of the border. The label is left as you set it; leave it empty for an icon only, and say what it does with SetToolTip().

status_t r5_button_set_icon(BButton* button, r5_icon which, float buttonHeight);

A predefined icon. Pass the height of a text button on the same row, for example revert->PreferredSize().height.

status_t r5_button_set_vector(BButton* button, const uint8* data, size_t size, float buttonHeight); status_t r5_button_set_file_icon(BButton* button, const char* path, float buttonHeight); status_t r5_button_set_mime_icon(BButton* button, const char* type, float buttonHeight);

The same for an HVIF buffer, a file's icon, or a MIME type's icon.

status_t r5_button_set_lock(BButton* button, bool locked, float buttonHeight);

The closed lock when locked is true, the open lock otherwise. It does not open a password window: the caller decides what a click does.

Each returns B_OK when the icon was set. A valid button is still made square when the picture could not be loaded, so the row does not jump. A NULL button or a height below 1 returns B_BAD_VALUE.

r5_glyph

enum and functions

Haiku's icon set has no power symbol, no circular arrow, no small clock face and no eye. For those, the kit draws a line glyph in code: one color, given by the caller, so it follows the text color and dark mode. Glyphs are small symbols beside text. A full icon still comes from Haiku's HVIF set.

ValueNumberPicture
R5_GLYPH_POWER1A ring open at the top, with a stem in its middle
R5_GLYPH_RESTART2A ring open at the right, with an arrow head at the top
R5_GLYPH_CLOCK3A clock face with two hands
R5_GLYPH_EYE4An open eye: show the password
R5_GLYPH_EYE_OFF5The eye with a line through it: hide the password
R5_GLYPH_LOG_OUT6An open door frame with an arrow out to the right
void r5_glyph_draw(BView* view, r5_glyph which, BRect frame, rgb_color color);

Draws the glyph inside frame. The view's drawing state is the same afterwards.

BBitmap* r5_glyph_bitmap(r5_glyph which, float side, rgb_color color);

A new B_RGBA32 bitmap with the glyph on a transparent background. The edges keep their soft coverage in the alpha channel. The caller deletes it.

status_t r5_button_set_glyph(BButton* button, r5_glyph which);

Puts the glyph before the label, in B_CONTROL_TEXT_COLOR, at the size of the button's font. Unlike r5_button_set_icon(), the button keeps its own width and height. Set the font first, and call it again after B_COLORS_UPDATED.

BButton* restart = new BButton("reboot", "Restart", new BMessage(kRebootAction));
restart->SetFont(&buttonFont);
r5_button_set_glyph(restart, R5_GLYPH_RESTART);

r5_icon

enum

The predefined icons. They are the unmodified Haiku and Tracker pictures. The numbers are part of the contract: a new icon is added at the end, with the next number.

ValueNumberPicture
R5_ICON_BACK1The arrow Tracker draws in its location bar
R5_ICON_FORWARD2Tracker's forward arrow
R5_ICON_UP3Tracker's up arrow
R5_ICON_HOME4The house Tracker draws on the home folder
R5_ICON_UNLOCKED5Haiku's Action_Login, an open lock
R5_ICON_LOCKED6Haiku's Action_Logout, a closed lock
