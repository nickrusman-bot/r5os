What sets R5 apart

Beyond standard Haiku.

Thoughtful additions for everyday work, audio, networking, and multi-user security — while keeping every existing Haiku application right at home.

One Settings app. Not twenty.

Instead of scattered preference panels, R5 brings System and Personalization together in one unified window with instant apply, Revert, Defaults, and interactive screen placement — while keeping the classic standalone tools installed.

Smarter Tracker & Deskbar.

Shift-click column headers for multi-column sorting, press Command+A in path fields, switch to Dark Mode, and enjoy a cleaner Deskbar leaf menu without unnecessary scroll arrows.

Pro-audio & AirPlay built in.

Switch audio buffers to Low latency (256 frames) or Pro audio (128 frames), configure USB 5.1/7.1 or headphone Virtual surround, hot-plug sound devices without restarting media, and stream to Wi-Fi speakers via AirPlay 1.

Wi-Fi, IPv6 & AirPrint.

Join and auto-reconnect to Wi-Fi networks from a single screen, use automatic IPv6 (SLAAC) alongside IPv4, and add network printers directly over AirPrint / IPP.

No more running as root.

Standard Haiku boots straight into uid 0. R5 introduces a real Sign in screen, Lock screen, Log out, standard accounts with private 0700 home folders, and a shared administrator lock for machine settings.

Ready for VirtualBox & real metal.

Includes Mesa 25, VulkanTeapot, and built-in VirtualBox 7.2.22 Guest Additions so the desktop resizes automatically with your VM window and mounts host shares on the Desktop.

One OS. Three 64-bit targets.
100% binary and API compatibility with Haiku libbe applications on the same architecture.
